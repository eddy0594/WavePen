# 說寫 WavePen 安裝說明

說寫是一個 Mac 上的 AI 語音輸入工具：按住快速鍵說話，放開後，整理好的文字就會直接打進你正在用的 App（LINE、Gmail、Word、Notion……都可以）。

支援 macOS 12 以上，Apple 晶片（M1～M4）和 Intel Mac 都能用。

---

## 1. 安裝

1. 打開 `WavePen_1.0.0_universal.dmg`。
2. 把「WavePen」圖示拖到右邊的「Applications（應用程式）」資料夾。
3. 退出 DMG（在 Finder 側邊欄按退出鍵）。

## 2. 第一次打開（只需要做一次）

因為這個 App 沒有向 Apple 付費公證，第一次打開時 macOS 會擋下來，這是正常的。

1. 到「應用程式」資料夾，雙擊「WavePen」。會跳出「無法打開」的警告，按「完成」。
2. 打開「系統設定」→「隱私權與安全性」，捲到最下面。
3. 會看到「已阻擋 WavePen 以保護你的 Mac」，按旁邊的「**強制打開**」（或「仍要打開」）。
4. 輸入 Mac 密碼，再按一次「打開」。

之後就可以像一般 App 一樣正常打開了。

> 如果找不到「強制打開」按鈕，可以打開「終端機」貼上這行指令後按 Enter，再重新打開 App：
>
> ```bash
> xattr -dr com.apple.quarantine /Applications/WavePen.app
> ```

## 3. 準備 API Key

說寫會用 OpenAI 的服務來辨識語音和整理文字，所以需要一把 OpenAI API Key。按用量計費，每個月說 8,000 字大約新台幣 10～15 元。

1. 到 <https://platform.openai.com/> 註冊並登入。
2. 在「Billing」儲值（最低 5 美元就夠用很久）。
3. 到「API keys」按「Create new secret key」，複製那串 `sk-` 開頭的文字。

> 如果是親友把 Key 給你，直接用那一把即可。Key 等同於付費帳號的密碼，請不要貼到公開的地方。

## 4. 設定精靈

第一次打開會進入設定精靈：

1. **歡迎**：選擇「繁體中文」。
2. **語音辨識**：服務選「OpenAI (GPT-4o Transcribe)」，貼上 API Key，按「測試」，出現成功後按「下一步」。
3. **AI 潤飾**：服務選「OpenAI」，貼上同一把 API Key，按「測試」，成功後按「下一步」。
4. **權限**：依照畫面開啟權限（見下一節）。
5. **試用**、**完成**。

API Key 存放在 Mac 的「鑰匙圈」裡，不會上傳到任何說寫的伺服器。

## 5. 開啟權限

說寫需要以下權限才能正常運作，請在「系統設定」→「隱私權與安全性」裡把「WavePen」打開：

| 權限 | 用途 | 沒開會怎樣 |
| --- | --- | --- |
| 麥克風 | 錄下你的聲音 | 完全不能用 |
| 輔助使用 | 把文字打進其他 App | 文字只會複製到剪貼簿，要自己按 ⌘V 貼上 |
| 自動化（選用） | 判斷你在 Gmail、Google 文件等網頁，調整語氣 | 一樣能用，只是語氣調整比較不準 |

開完「輔助使用」後，建議把說寫完全結束（選單列圖示 → 結束）再重新打開一次。

## 6. 怎麼用

| 功能 | 快速鍵 | 說明 |
| --- | --- | --- |
| 聽寫 | 按住 `Fn`（🌐），可在設定改成右 Option | 按住說話，放開後整理好的文字會邊產生邊打進去 |
| 問問題 | `Fn` + `空白鍵` | 說出問題，答案會出現在小視窗 |
| 翻譯選取的文字 | `Fn` + `左 Shift` | 先選取一段文字，再按快速鍵說出要翻成什麼 |

小技巧：

- **改寫**：先選取一段文字，再按住 `Fn` 說「幫我改得正式一點」，選取的文字就會被替換。
- **中英夾雜**沒問題，說「幫我把這份 report 寄給 Amy」會照原樣輸出。
- 輸出一律是**繁體中文（台灣用語）**，可以在「設定」→「語音辨識」→「中文輸出」更改。
- **自動學習錯字**：說寫打完字後一分鐘內，如果你把某個詞改掉（例如「論識」改成「潤飾」），它會自動記進詞典，下次就辨識得更準。錄音小膠囊會顯示「已學會」，按「復原」可以取消。備忘錄、郵件和多數網頁輸入框都支援；LINE、Slack 等 App 可能無法偵測。
- **專有名詞**：常用的人名、產品名可以先加到「設定」→「詞典」，辨識時會優先採用。
- **隱藏 Dock 圖示**：「設定」→「一般」→「更多設定」關閉「在 Dock 顯示圖示」，之後從選單列圖示開啟說寫。

> **按 Fn 會跳出表情符號視窗？** 到「系統設定」→「鍵盤」，把「按下 🌐 鍵時」改成「不執行任何動作」。

## 7. 常見問題

**按快速鍵沒反應**
確認選單列有說寫的圖示（App 有在執行），並檢查「輔助使用」權限。在「設定」→「一般」可以改成其他快速鍵。

**文字沒有打進去，只有複製到剪貼簿**
「輔助使用」權限沒開，或開了之後沒有重新啟動說寫。如果更新過 App，可能要先把舊的 WavePen 從清單移除（按「−」）再重新加入。

**出現「API Key 無效」或「額度不足」**
到 OpenAI 網站確認 Key 沒有被刪除、帳戶還有餘額。

**想完全移除**
把「應用程式」裡的 WavePen 丟到垃圾桶；設定檔在 `~/Library/Application Support/com.wavepen.desktop`，一起刪除即可。
