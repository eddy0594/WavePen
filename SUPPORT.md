# Support

Looking for help with WavePen? Here's where to go:

## Community

- **Discord**: [Join our server](https://discord.gg/V6rRpJ4RGD) for real-time chat and quick help
- **GitHub Discussions**: [Issues](https://github.com/eddy0594/WavePen/issues) for questions and troubleshooting

## Bug Reports

If you've found a bug, please [open an issue](https://github.com/eddy0594/WavePen/issues/new?template=bug_report.yml) with steps to reproduce.

## Feature Requests

Have an idea? Start a [issue](https://github.com/eddy0594/WavePen/issues) first, or [open a feature request](https://github.com/eddy0594/WavePen/issues/new?template=feature_request.yml).

## Security

Found a security vulnerability? Please report it privately via [GitHub Security Advisories](https://github.com/eddy0594/WavePen/security/advisories/new). See [SECURITY.md](SECURITY.md) for details.
